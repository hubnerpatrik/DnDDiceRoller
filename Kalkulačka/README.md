Jak to spustit - KROK ZA KROKEM
Způsob 1: Visual Studio 

Otevři Visual Studio
Klikni na "Open a project or solution"
Najdi soubor DnDDiceRoller.csproj a otevři ho
Nahoře klikni na zelené tlačítko ▶️ "Start" (nebo zmáčkni F5)
Otevře se okno a můžeš házet kostkami!

Způsob 2: Příkazová řádka

Otevři příkazovou řádku (Command Prompt nebo PowerShell)
Přejdi do složky s programem:

   cd cesta\k\DnDDiceRoller-Jednoduchy

Spusť program:

   dotnet run
Jak program používat
Po spuštění uvidíš menu:
1 - d4   (čtyřstěnná)
2 - d6   (klasická hrací)
3 - d8   (osmistěnná)
4 - d10  (desetistěnná)
5 - d12  (dvanáctistěnná)
6 - d20  (nejpoužívanější v D&D)
7 - d100 (percentile dice)
0 - Konec

Stiskni číslo kostky, kterou chceš hodit
Zmáčkni Enter
Uvidíš výsledek!
Pro ukončení stiskni 0
