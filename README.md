# D&D Dice Roller

Konzolová aplikace v C# pro simulaci házení kostkami v Dungeons & Dragons.

## Funkce
- Podpora všech standardních D&D kostek (d4, d6, d8, d10, d12, d20)
- Detekce kritických hodů na d20
- Jednoduché menu s možností opakovaného házení
- Náhodné generování výsledků

## Dostupné kostky
- d4 (čtyřstěnná)
- d6 (klasická hrací)
- d8 (osmistěnná)
- d10 (desetistěnná)
- d12 (dvanáctistěnná)
- d20 (nejpoužívanější v D&D)
